版本V1.0 MVP
目标用户4-12 岁儿童（操作者）+ 家长（购买决策者）
平台微信小程序原生 + 云开发
核心模块首页 · 敲鼓游戏 · AR 拍照 · 涂色装饰 · 商店 · 个人中心
技术栈WXML + WXSS + JS · 云数据库 · 云存储 · 云函数 (Node.js 18)

二、需求目标

目标类型描述衡量指标目标值
用户体验儿童能独立完成敲鼓游戏首次游戏完成率> 80%
留存小狮收集驱动回访7 日留存率> 30%

三、用户与使用场景

🧒 小明（7 岁）

喜欢鲜艳颜色和即时奖励，精细动作还在发育中。被舞狮吸引，想"变成小狮子"。

使用场景：放学后打开小程序玩敲鼓 → 拍照加狮头贴纸 → 涂色画狮子 → 收集解锁新小狮

👩 小明的妈妈

关注教育价值和安全性，愿意为优质文化产品付费。

使用场景：和孩子一起亲子敲鼓 → 浏览商店发现喜欢的文创 → 跳转小程序联盟下单

七、异常与边界处理

场景表现交互
网络断开Toast "网络已断开"保留当前页，缓存可继续
加载超时 >3s小狮转圈动画 + "加载中…"自动触发
加载超时 >8s弹窗 "检查网络" + [重试][返回]防止儿童无限等待
加载失败全屏错误页 + [重试]大圆角按钮
空列表居中插画 + CTA 按钮"来试试敲鼓和涂色吧！"
相机拒绝引导去设置页不阻塞其他功能
帧率 <30fps自动关闭粒子特效纯文字反馈替代
儿童误触12pt dead zone / 清空确认弹窗防误触保护
