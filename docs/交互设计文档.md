### 1.2 导航规则

| 导航类型 | 规则 |
|---------|------|
| 底部 Tab 切换 | 非资源页面（商店/个人中心）：保留状态，不重新加载<br>资源页面（敲鼓/AR/涂色）：切 tab 时释放相机/音频资源并销毁页面，返回时重建 |

| 解锁动画 | 居中弹窗 + 缩放出现 + 全屏半透明遮罩，自动 3s 后消失 |
| 返回首页 | 统一使用 🏠 图标按钮，非 `< 返回` |

### 2.1 触摸目标尺寸

| 用户 | 最小触摸目标 | 说明 |
|------|------------|------|
| 儿童（4-12 岁） | 56pt × 56pt | 底部导航使用微信标准：icon 显示尺寸 27pt × 27pt（提供 3x 资源 81px），点击区域为整个 tab 栏位（icon+文字区域），不依赖 padding 扩展 |
| 家长 | 44pt × 44pt | 微信原生标准 |
| 关键操作按钮 | ≥ 64pt 高度 | "去购买"、"保存"、"重试"等 |

### 2.2 通用手势

| 手势 | 用途 | 备注 |
|------|------|------|
| 点击（tap） | 选择、确认、进入 | 所有可点元素需有 pressed 态（缩放 0.95 + 透明度 0.8） |
| 长按（long-press） | 个人中心 AR 照片列表删除 | 触发时长 800ms，弹窗确认删除 |
| 拖拽（drag） | 装饰物放置、贴纸位置调整 | 设 12pt dead zone：手指移动 < 12pt 视为 tap 而非 drag，防 4 岁儿童误触 |
| 双指缩放（pinch） | 贴纸大小调整 | 仅在贴纸编辑页生效 |
| 左右滑动（swipe） | 商品轮播图、曲目列表横向扩展 | 支持惯性滑动，若 child 在可滑动区域内 tap，优先响应 tap |
| 下拉（pull down） | 刷新数据 | 商店列表、个人中心数据 |

- **手势优先级**：tap > swipe > drag > long-press。同一元素上多种手势不会同时激活。拖拽必须移动超过 dead zone 才触发，否则降级为 tap。

### 2.3 触感反馈

| 操作 | 反馈 |
|------|------|
| 鼓面敲击 | 短震动 + 对应音效 |
| 按钮点击 | 无震动，视觉 pressed 态即可 |
| 解锁动画 | 长震动（成功感） |
| 评级 S/A | 中震动 |
| 操作失败 | 短震动 + Toast |
| 装饰物吸附 | 轻震动 + 帧动画（放大弹回） |

### 2.4 加载 / 空状态 / 错误态

| 状态 | 表现 | 交互 |
|------|------|------|
| 页面加载 | 骨架屏（灰色脉冲矩形，形状≈内容轮廓） | 无交互 |
| 组件加载 | 局部 loading spinner（小程序原生 loading） | 无交互 |
| 加载超时（> 3s） | 骨架屏切换为趣味动画（小狮转圈/打哈欠）+ "加载中…" 文案 | 超时 3s 自动触发，防止儿童因等待而困惑 |
| 加载超时（> 8s） | 弹窗："加载太久了，检查一下网络吧？" [重试] [返回首页] | 防止儿童无限等待 |
| 下拉刷新 | 顶部 loading 动画 + "刷新中…" | 手指上滑可取消 |
| 空列表 | 居中插画 + 文案 + CTA 按钮 | 文案示例："还没有作品，来画一张吧！" |
| 网络错误 | Toast "网络已断开" + 保留当前页 | 不阻塞操作，已缓存内容可继续 |
| 加载失败 | 全屏错误页 + 重试按钮（大圆角） | 点击重试 |
| 首次使用引导 | 半透明遮罩 + 动画演示 + "我知道了"按钮 | 遮罩不可穿透，必须点击按钮关闭 |

### 2.5 页面过渡动画

| 场景 | 动画 | 时长 | 曲线 |
|------|------|------|------|
| 页面 Push | 从右滑入 | 320ms | ease-out |
| 页面 Pop | 从左滑出 | 280ms | ease-in |
| Tab 切换 | 无动画，即时切换 | 0ms | — |
| 弹窗出现 | 从底部上滑 + 遮罩 fade in | 300ms | ease-out |
| 弹窗关闭 | 下滑 + 遮罩 fade out | 250ms | ease-in |

| 解锁动画 | 中心缩放（0→1.1→1）+ 遮罩 fade in | 300ms | spring |
| 保存完成 | 页面从底部上滑（半屏卡片） | 350ms | ease-out |

## 4. 敲鼓节奏游戏交互

### 4.1 模式选择弹窗（V2.5 已移除 — 单人/亲子模式已合并为统一游戏页）

> **已废弃。** V2.5 起，首页 Hero 卡片点击直接进入曲目列表页，不再弹"选择玩法"弹窗。单人模式与亲子配合模式已合并，游戏内自动识别为单人还是亲子玩法。

### 4.2 曲目列表页

**页面结构：** 顶栏（← 返回 + "选择曲目" 标题）+ 曲目卡片列表 + 底部小狮解锁状态栏。

| 元素 | 交互 |
|------|------|
| 曲目卡片 | 点击进入该曲目的倒计时页 |
| 已挑战曲目 | 显示最佳评级 + 星星 |
| 未挑战曲目 | 显示"未挑战" |
| 火火狮/木木狮状态提示 | 展示解锁状态，不可点击 |
| ← 返回 | 返回首页 |

**曲目卡片规格：** 335×100px、圆角 16px、红底 #F36F59 白色文字。左侧歌曲信息区（标题 20px Semibold 白色 + 副标题 12px rgba(255,255,255,0.75)），右侧星级评分。卡片间间距 12px。

**底部小狮解锁状态栏：** 2 行（火火狮 + 木木狮），#FFF5F3 实底背景、圆角 12px。已解锁显示彩色文字，未解锁灰色 + 🔒。

- 曲目卡片点击：缩放 0.95 → 弹回 1.0 → 跳转倒计时
- 首次进入自动高亮推荐曲目（easy），3s 无操作自动进入
- 点击 ← 返回首页（非曲目选择页的上一级弹窗）

### 4.3 倒计时页

**页面结构：** 全屏深色背景，无顶栏、无返回按钮、无 IP 占位区。仅显示居中"准备"标题 + 品牌红色倒计时数字。

**设计要点：**
- 倒计时期间**不显示返回按钮**，用户无法退出
- **移除** IP 占位区（蓄势动画）
- 仅保留"准备"标题 + 倒计时数字两个元素

| 元素 | 规格/行为 |
|------|----------|
| "准备" 标题 | `position: absolute; left: 0; right: 0; text-align: center`，MiSans Latin Bold 20px `#000000` |
| 倒计时数字 | `position: absolute; top: 50%; left: 0; right: 0; text-align: center; transform: translateY(-50%)`，品牌红 `#E31E15`，240rpx Heavy，pulse 缩放动画（0.8→1.12→1.0） |

| 动画 | 时序 |
|------|------|
| 数字显示 | "3" → 0.6s → "2" → 0.6s → "1" → 0.6s → "开始！" |
| 数字动画 | pulse 缩放 1.2→1.0 + fade in/out，每步 0.6s |
| "开始！" 后 | 立即自动进入游戏页，无延迟 |

- 退出行为：倒计时期间不可退出（无返回按钮），倒计时完成后自动进入游戏

#### 4.4.0.1 动态 IP 动作图（V2.5 新增）

| combo 区间 | 图片文件 | 形象描述 |
|-----------|---------|---------|
| 0 ~ 1 | `miniprogram/images/ip-actions/活力满满.png` | 活力满满 |
| 2 ~ 4 | `miniprogram/images/ip-actions/自信就位.png` | 自信就位 |

#### 4.4.1 6 种敲击模式

| 模式 | 鼓棒 | 音波提示 | 命中区虚线 |
|------|------|---------|-----------|
| 中心左面 | 左棒 -25° | 左侧 25% | 中心圆左半区圆形虚线 (50×50, 发光脉冲) |
| 中心右面 | 右棒 25° | 右侧 75% | 中心圆右半区圆形虚线 (50×50) |
| 中心双面 | 双棒同时 | 正中心 | 中心大圆形虚线 (80×80) |
| 边缘左侧 | 左棒 -45° | 左侧边缘 | 左边缘竖线 (24×56) |
| 边缘右侧 | 右棒 45° | 右侧边缘 | 右边缘竖线 (24×56) |
| 边缘两侧 | 双棒同时 | 正中心 | 两侧边缘标记同时亮 |

**鼓棒：** 160px 长，半透明棒身 + 6rpx 实线边缘（#CCCCCC 默认），在外圈缩至与内圈重合（scale≤1.0）时出现。敲击后按判定结果变色（红/绿/金/灰）。
**缩圈提示：** 外圈光环从 2.5x→0.4x 向内收缩（1.5s），提示敲击时机

**节奏：** 约 800ms/拍（原型）
**miss 超时：** 2000ms 未敲击 = 自动 miss

#### 4.4.2 判定规则（缩圈判定）

所有节拍均通过**外圈缩圈**机制判定：外圈（光环）从 2.5x 向内收缩至 0.4x，速率 1.5s/圈。用户敲击时根据当前外圈与内圈（=1.0x）的重合度判定：

| 判定 | 缩圈比例(scale) | 语义 | 得分 | 连击 | 鼓棒颜色 |
|------|----------------|------|------|------|---------|
| ✨ 太棒啦 | 0.9 ≤ scale ≤ 1.1 | 外圈≈内圈（±10%） | 200 | combo+1 | #E31E15 红 |
| 👍 不错哦 | 1.1 < scale ≤ 1.4 | 外圈接近内圈 | 100 | combo+1 | #65B96A 绿 |
| ⚡ 太快啦 | scale > 1.4 | 外圈离内圈远 | 50 | combo清零 | #FFB020 金 |
| 😅 漏掉了 | scale < 0.9 | 外圈已缩过内圈 | 0 | combo清零 | #C9CDD4 灰 |

- 每 tick 20ms（50fps），scale 变化约 0.028/tick
- 防抖：同一节拍 300ms 内不重复判定
- 超时：用户未敲击 → 外圈缩至 0.4 → 自动判"漏掉了"
- 连击≥2 → 自信就位；≥5 → 威风凛凛；断连 → 眼睛发亮

### 4.5 亲子游戏页（分屏，V2 预留）

| 区域 | 交互 |
|------|------|
| 上半屏（家长） | 同单人游戏鼓面交互 |
| 下半屏（孩子） | 全屏仅显示 3 个大图标（⭐🦁💥，占屏幕 1/3）随机出现 |

- 孩子侧图标出现规则：每 3-5s 随机出现一个，持续 4s

## 9. 通用组件交互规范

### 9.1 底部导航栏

| 状态 | 表现 |
|------|------|
| 未选中 | 黑白 icon（尺寸见图标规范）+ 灰色文字 `#AAAAAA` 12px Medium Inter |
| 选中 | 彩色 icon + 彩色文字 `#E31E15` 12px Semi Bold Inter |
| 点击 | icon 缩放 0.9 → 弹回 1.0 / 120ms |
| Badge | 右上角红点（仅"我的"有更新时显示，如有新解锁） |

- 固定在底部，不随页面滚动
- 高度：132rpx (66px)
- **显示/隐藏规则：** 首页、商店、个人中心始终显示；进入游戏子页面（曲目选择/倒计时/游戏进行/游戏结果）时隐藏，返回首页时恢复显示
- icon 资源：使用 `tab-home.png` / `tab-shop.png` / `tab-mine.png`（含 active 变体），128×128 px，小程序 3x 适配
- 点击区域：整个 tab 栏位（icon+文字），不依赖 padding 扩展
- 导航栏高 66px，背景 `#FFFFFF`
- 文字在 icon 下方 3px

### 9.2 Toast 提示

| 类型 | 样式 | 位置 |
|------|------|------|
| 成功 | 绿色 + ✓ | 顶部 |
| 错误 | 红色 + ✕ | 顶部 |
| 信息 | 灰色 + ℹ️ | 顶部 |
| 解锁条件 | 底部卡片式 + 🦁 | 底部 |

- 显示时长：2s（成功/信息），3s（错误/解锁条件）
- 支持同时只显示一个 toast

### 9.3 确认弹窗
