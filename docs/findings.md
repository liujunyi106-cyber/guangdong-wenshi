# 发现与决策

## 需求
- 核心用户：4-12 岁儿童 + 家长（购买决策者）
- 要解决的事：通过"玩"体验舞狮乐趣，激发文化好奇心和购买欲
- 产品形态：微信小程序

## 研究发现
- 参考论文：基于广东醒狮文化的数字化互动体验设计与研究（温玉婷）

## 技术决策
| 决策 | 理由 |
|------|------|
| 微信小程序 + 微信云开发 | 微信生态，自动授权登录 |
| 小程序联盟替代微信支付 | 无企业支付资质 |
| AR V1 贴纸版 | 降低技术门槛，快速上线 |

## 风险决策
| 风险 | 结论 |
|------|------|
| 价值风险 | 等级称号激励 + AR 社交裂变 |
| 商业风险 | 自建商店分佣，协会暂不接触 |
| 技术风险 | AR 贴纸 V1 → 实时滤镜 V2 |
| IP 设计 | 已有设计稿 |

## 本次会话新增（2026-06-18 d）
| 决策 | 理由 |
|------|------|
| 微信小程序原生框架 | 无需跨端，Canvas/音频/相机需要最佳性能 |
| Taro/uni-app 不采用 | 增加复杂度，鼓点 ±80ms 精度无法保证 |
| 云存储直接托管素材 | V1 量级小，免费额度足够，无需额外 CDN |
| 数据库 9 个集合 | 用户/成绩/作品/照片 + 5 个 CMS 配置 |
| 云函数 6 个 | 登录/配置/成绩/上传/用户数据/删除 |
| 开发顺序 4.1→4.9 | 骨架→组件→云→首页→游戏→涂色→个人→AR→商店 |
| 免版税音频来源 | Freesound / Pixabay Music |
| 鼓点判定用 Date.now() | 不依赖音频播放进度，精度更高 |
