## 0. OpenCode 读取说明

请把本文档当作**品牌设计约束 + UI 生成规范**，不是营销稿。生成代码、组件、页面样式时必须优先遵守以下规则：

1. 所有页面保持儿童友好：大按钮、大图标、少文字、强反馈、动画引导。
2. 视觉必须围绕“Q 萌广东醒狮小狮 IP”展开，避免写实、国潮厚重、成人化、暗黑风。
3. 主色使用红金白，辅色用于五只小狮的属性识别。
4. 小程序首屏要突出“敲鼓游戏”，AR 拍照和涂色装饰作为次级入口。
5. 解锁、收集、成就反馈是品牌体验的一部分，不是普通业务弹窗。
6. 不要在页面中出现参考图水印“即梦AI”，水印不是品牌元素。

## 1. 品牌一句话

**广东舞狮文创**是一个面向儿童的舞狮互动文创小程序：通过敲鼓、AR 贴纸拍照、狮头涂色装饰，让孩子在“玩”的过程中解锁小狮 IP，形成收集欲与购买兴趣。

### 1.1 品牌核心链路

```text
玩 → 解锁小狮 → 激发兴趣 → 商店浏览 → 小程序联盟 / 带货组件购买
```

### 1.2 品牌关键词

```text
岭南醒狮 / 儿童玩乐 / Q萌收藏 / 红金喜庆 / 软萌毛绒 / 鼓点节奏 / 解锁成就 / 文创周边
```

### 1.3 品牌气质

| 维度 | 要求 |
|---|---|
| 情绪 | 热闹、开心、勇敢、可爱、有仪式感 |
| 文化感 | 来自广东醒狮，但表现方式儿童化、游戏化 |
| 视觉感 | 3D 软胶 + 毛绒边 + 红金鼓台 + 圆润高光 |
| 交互感 | 像玩具一样可点、可敲、可拖、可收集 |
| 商业感 | 商店像“IP 周边橱窗”，不要像硬销售电商页 |

## 2. 产品与人群约束

### 2.1 产品定位

微信小程序，免费使用。通过“敲鼓 / 拍照 / 涂画”让 4–12 岁儿童体验舞狮乐趣，并激发对舞狮 IP 周边的拥有欲。

### 2.2 目标用户

| 用户 | 设计侧重点 |
|---|---|
| 儿童 4–12 岁 | 操作简单、图形明确、反馈强烈、按钮大、文案短 |
| 家长 | 浏览商店、理解商品、完成购买跳转、查看孩子作品 |

### 2.3 儿童交互硬性规则

| 项目 | 规则 |
|---|---|
| 点击热区 | 主要按钮高度不低于 `88rpx`；核心操作不低于 `104rpx` |
| 图标 | 核心图标不低于 `96rpx`；亲子助威图标建议占屏幕宽度 1/3 |
| 文案 | 单句不超过 12 个中文字符，优先使用“动词 + 名词” |
| 首次引导 | 使用半透明遮罩 + 动画演示 + “知道了”大按钮 |
| 错误提示 | 用鼓励语，不使用严厉、失败、惩罚式表达 |

## 3. IP 视觉 DNA

### 3.1 主 IP 描述

参考图中的主形象是一个**Q 版醒狮小孩 / 小狮灵**：头戴红金醒狮头盔，白色厚绒毛包边，橙红渐变眼睛，金色装饰件，身穿红色小褂，脚踩红金鼓台。胸前可保留“野”字作为当前主视觉记忆点；若后期确定正式名称，可把“野”替换成正式品牌字。

### 3.2 造型关键词

```text
圆头大眼 / 短手短脚 / 厚绒毛 / 红金醒狮头 / 小鼓台 / 云纹金饰 / 鼓钉 / 奶油肤色 / 软胶高光 / 微嘟嘴
```

### 3.3 IP 比例建议

| 部位 | 视觉比例 |
|---|---|
| 头部 + 狮头帽 | 占角色总高 55%–65% |
| 身体 | 占总高 25%–30%，短小圆润 |
| 手脚 | 短、肉感、圆指头，不画复杂关节 |
| 眼睛 | 大，橙红渐变，带高光 |
| 绒毛 | 体积厚，边缘柔软，不做尖锐毛刺 |
| 鼓台 | 红色圆鼓 + 金色鼓钉 + 云纹装饰，作为舞狮舞台符号 |

### 3.4 材质风格

| 材质 | 用法 |
|---|---|
| 毛绒 | 狮头眉毛、腮边、披风边、衣摆边；颜色偏暖白 |
| 软胶 / 盲盒质感 | 皮肤、脸、手脚、红色衣服，保留柔和高光 |
| 金属 | 鼓钉、头盔金饰、边框；使用暖金，不用冷铜 |
| 漆面鼓 | 鼓面和鼓身，红色带轻微高光 |

### 3.5 表情规范

| 表情 | 场景 |
|---|---|
| 微嘟嘴 / 倔强脸 | 游戏入口、未解锁、准备状态 |
| 张手欢呼 | 通关、解锁、保存成功 |
| 合掌祝福 | 保存完成、分享、称号解锁 |
| 趴伏 / 蓄势 | 游戏加载、亲子配合准备状态 |
| 单脚平衡 | 舞狮动作、亲子配合、成就页 |

### 3.6 禁止项

```text
禁止写实狮头 / 禁止恐怖表情 / 禁止尖锐獠牙过长 / 禁止暗黑低饱和 / 禁止成人潮牌化 / 禁止复杂花纹堆满屏 / 禁止小字说明过多 / 禁止出现“即梦AI”水印
```

| 小狮 | emoji | 色彩 | 性格 | 解锁条件 | UI 用途 |

| 火火狮 | 🔥 | 红色 | 活泼好动 | 敲鼓通关任意曲目 | 新手激励、敲鼓主视觉 |

| 火火狮 | 红色主衣、火焰纹、小鼓点粒子 |

| 金金狮 | 金色徽章、星光粒子、奖牌动作 |
| 木木狮 | 绿色腰带、叶片纹、稳定站姿 |

## 6. 字体与文案

### 6.1 字体

设计稿使用三套字体，小程序中按优先级回退：

```css
/* 中文标题/正文 */
font-family: "MiSans Latin", "PingFang SC", "Microsoft YaHei", sans-serif;

/* 英文/数字 UI */
font-family: "Inter", system-ui, -apple-system, sans-serif;

/* 英文装饰（Hero） */
font-family: "DIN", "Inter", system-ui, sans-serif;
```

| 字体 | 角色 | 使用场景 |
|------|------|---------|
| **MiSans Latin** | 中文主字体 | 标题、正文、功能入口文案 |
| **Inter** | 拉文/数字 | 状态栏、底部导航文字、辅助标注 |
| **DIN** | 装饰字体 | Hero 英文点缀（"Hello!"） |

### 6.2 字号层级

| 层级 | px | rpx | weight | 字体 | 用途 |
|------|-----|-----|--------|------|------|
| Hero EN | 38 | 76 | 700 | DIN | "Hello!" 英文点缀 |
| Hero Title | 30 | 60 | 700 | MiSans | "一起来敲鼓" |
| Page Title | 20 | 40 | 630 | MiSans | "小狮子""狮子拍照""狮子绘画" |
| Sub Title | 16 | 32 | 520 | MiSans | "舞狮趣闻" 子区域标题 |
| Card Sub | 12 | 24 | 380 | MiSans | 卡片副标题 |
| CTA | 12 | 24 | 520 | MiSans | CTA 按钮文字 |
| Status | — | — | — | — | 纯黑底 #1E1E1E，无文字 |
| Tab Active | 12 | 24 | 600 | Inter | 底部导航选中态 |
| Tab Inactive | 12 | 24 | 500 | Inter | 底部导航未选中态 |

### 6.3 文案语气

| 场景 | 推荐表达 | 避免表达 |
|---|---|---|
| 通关 | “完成啦！”“舞狮大师！” | “任务结束”“数据结算” |
| 失败/低分 | “再试一次吧！”“继续加油！” | “失败”“太差了” |
| 未解锁 | “先解锁才能使用” | “无权限”“不可用” |
| 保存 | “已保存”“再做一张” | “上传成功到数据库” |
| 加载失败 | “加载失败，请检查网络后重试” | “接口报错” |

## 7. 图形、图标与装饰

### 7.1 图标风格

| 项目 | 规则 |
|---|---|
| 造型 | 圆角、胖短、儿童玩具感 |


## 15. 验收清单

### 15.1 品牌一致性

- [ ] 页面第一眼能看出“儿童舞狮文创”而不是普通儿童游戏。
- [ ] 主色为红金白，辅色只用于小狮属性区分。
- [ ] 小狮造型圆润、软萌、有毛绒和盲盒质感。
- [ ] 没有出现参考图水印。
- [ ] 不使用写实、暗黑、成人化视觉。

### 15.2 儿童可用性

- [ ] 主要按钮足够大，儿童可轻松点击。
- [ ] 文案短，能用图标和动画说明的地方不堆文字。
- [ ] 错误反馈不打击孩子，使用鼓励语。
- [ ] 首次操作有动画引导。
- [ ] 复杂数据默认折叠。

### 15.3 PRD 对齐

- [ ] 首页包含小狮展示区、敲鼓主入口、AR/涂色次入口。
- [ ] 底部导航为：首页 / 商店 / 我的。
- [ ] 敲鼓通关解锁火火狮，S/A 解锁木木狮。
- [ ] AR 拍照使用解锁水水狮。
- [ ] 涂色完成作品解锁金金狮。
- [ ] 前 4 只集齐后自动解锁土土狮。
- [ ] 收集 ≥ 3 只显示“舞狮小传人”。
- [ ] 商店通过小程序联盟/带货组件跳转，不自建支付。
