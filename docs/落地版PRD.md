## 1. 产品概述

### 1.1 产品定位

通过"玩"（敲鼓 / 拍照 / 涂画）让 4–12 岁儿童体验舞狮乐趣，激发对舞狮文化的好奇心和"想要拥有"的购买欲。微信小程序形态，免费使用。

### 1.2 目标用户

| 角色 | 说明 |
|------|------|
| 儿童（4–12 岁） | 直接使用者，操作敲鼓 / AR 拍照 / 涂色装饰 |
| 家长 | 购买决策者，浏览商店完成购买 |

全年龄跨度不分区，交互上统一适配儿童（大图标、简单文案、动画引导替代文字说明）。

### 1.3 核心转化链路

```
玩 → 解锁小狮 → 激发兴趣 → 商店浏览 → 小程序联盟 / 带货组件购买
```

解锁激励贯穿所有功能：

| 功能 | 解锁 | 小狮 |
|------|------|------|
| 敲鼓通关 | 火火狮 | 🔥 |
| 敲鼓 S/A 评级 | 木木狮 | 🌿 |
| AR 拍照使用 | 水水狮 | 💧 |
| 涂色完成作品 | 金金狮 | ✨ |
| 收集满 4 只 | 土土狮（隐藏） | 🪨 |
| 收集 ≥ 3 只 | 称号"舞狮小传人" | — |

### 1.4 产品架构

```
                        广东舞狮文创小程序
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
      首页                  商店                  我的
   ┌────┼────┐            列表/详情            收集/作品/记录
   │    │    │               │
  敲鼓  AR  涂色            小程序联盟
  游戏  拍照 装饰
```

底部导航栏：**🏠 首页 / 🛒 商店 / 👤 我的**（三级 tab，无返回按钮）。

## 3. 敲鼓节奏游戏

### 3.1 已确认事项

- 曲目：首版 2 首（easy + medium），免版税音频素材
- 通关定义：完成曲目即通关（火火狮解锁条件）
- 评级：S / A / B / C，仅作成就感反馈；A 以上（S / A）为「高分评价」（木木狮解锁条件）
- 亲子模式孩子侧：点屏幕大图标（⭐ / 🦁 / 💥）助威，非摄像头识别
- 鼓面交互：5 种敲击模式（中心左/右面单敲、中心双面齐敲、左右边缘单/双敲），用鼓棒飞入 + 外圈缩圈提示（2.5→0.4，1.5s），点击鼓面命中区响应。判定基于缩圈scale：太棒啦(0.9-1.1)/不错哦(1.1-1.4)/太快啦(>1.4)/漏掉了(<0.8)
- 成绩页仅用星级展示，折叠统计详情

### 3.4 状态机

```
[*] → idle → (选曲目) → loading → (加载完成) → ready
ready → (倒计时结束) → playing
playing → (曲目结束) → result_win / result_fail
playing → (切后台) → paused_auto → (恢复) → playing
playing → (暂停键) → paused_manual → (继续) → playing / (退出) → idle
result_win → (首次通关) → reward → (动画结束) → idle
result_win → (非首次) → idle
result_fail → (重试) → playing / (放弃) → idle
```

### 3.5 评级规则

| 评级 | 星星 | 动作图 | 条件 | 文案 | 作用 |
|------|------|--------|------|------|------|

| A | ⭐⭐⭐⭐ | 活力满满 | perfect ≥ 35% 且 miss < 20% | "好棒呀！舞狮小能手！" | 木木狮解锁条件 |
| B | ⭐⭐⭐ | 自信就位 | miss < 40% | "不错哦！再练练就更好了！" | 通关 |
| C | ⭐⭐ | 眼睛发亮 | miss ≥ 40% | "加油加油！你可以的！" | 通关 |

> 评级门槛已考虑 4 岁儿童协调能力适度放宽。

### 3.6 异常处理

| 场景 | 处理 |
|------|------|
| 游戏中途退出 | 弹窗确认 → 保存/取消 |
| 切后台/来电 | 自动暂停 → 恢复弹窗 |
| 网络中断 | toast 提示，已加载内容可继续 |
| 资源加载失败 | 弹窗重试，3 次后返回 |

| 倒计时中退出 | 无可退出按钮，倒计时自动完成后进入游戏 |

### 4.4 异常处理

| 场景 | 处理 |
|------|------|
| 相机权限拒绝 | 分平台引导（Android→wx.openSetting；iOS→文字引导） |
| 相册权限拒绝 | 保存时弹窗引导，仅在保存时触发 |
