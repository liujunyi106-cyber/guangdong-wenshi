# 广东舞狮文创小程序 · 技术规划文档

> 版本：V1.1 | 依赖：落地版 PRD V1.4 + 交互设计文档 V2.3 | 日期：2026-06-18 (f)

## 1. 技术栈选型

### 1.1 框架：微信小程序原生

| 方案 | 结论 |
|------|------|
| Taro / uni-app | ❌ 仅微信平台，无跨端需求；Canvas/音频/相机性能不如原生 |
| **微信小程序原生** | ✅ 鼓点判定（±80ms 精度）、Canvas 2D 涂色、相机取景均需最佳性能 |

### 1.2 后端：微信云开发

| 能力 | 用途 |
|------|------|
| 云数据库 | 用户数据、游戏记录、作品记录、CMS 配置 |
| 云存储 | 涂色作品图片、AR 拍照图片、贴纸/线稿/装饰素材 CDN |
| 云函数 | 登录鉴权、数据读写、素材管理 |

### 1.3 各模块技术选型

| 模块 | 核心技术 | 说明 |
|------|---------|------|
| 敲鼓节奏 | `wx.createInnerAudioContext` + `wx.vibrateShort` | 音频播放 + 触感反馈 |
| AR 贴纸 | `wx.createCameraContext` + Canvas 2D | 拍照 + 贴纸叠加合成 |
| 涂色装饰 | Canvas 2D (`<canvas type="2d">`) | 区域填充 + 装饰物拖拽 |
| 自由涂鸦 | Canvas 2D touch 事件 | 手指轨迹绘制 |
| 商店 | 纯前端展示 + `wx.navigateToMiniProgram` | 跳转小程序联盟 |
| 个人中心 | 云数据库读写 | 用户数据查询与展示 |

### 1.4 完整技术清单

```
前端框架：    微信小程序原生 (WXML + WXSS + JS)
后端服务：    微信云开发
  云数据库：  文档型数据库 (类 MongoDB)
  云存储：    CDN 文件存储
  云函数：    Node.js 18 运行时
登录鉴权：    wx.login + 云函数 getOpenId
用户信息：    头像填写组件 <button open-type="chooseAvatar">
             + 昵称输入 <input type="nickname">
            （wx.getUserProfile 已于 2022 年废弃，不可用）
音频引擎：    wx.createInnerAudioContext
相机：        wx.createCameraContext
画布：        Canvas 2D API (<canvas type="2d">)
触感：        wx.vibrateShort / wx.vibrateLong
分享：        wx.showShareImageMenu + wx.showShareMenu
跳转外链：    wx.navigateToMiniProgram (小程序联盟)
隐私弹窗：    wx.onNeedPrivacyAuthorization + 隐私协议页
版本管理：    Git + GitHub
开发工具：    微信开发者工具 (已安装)
```

## 4. 关键数据流设计

### 4.1 登录流程

```
小程序启动
  → wx.cloud.init() 初始化云开发
  → wx.login() 获取 code
  → 云函数 getOpenId(code) → 返回 openId
  → 本地缓存 openId
  → 查询 users 集合 { openId }
  → 存在 → 加载用户数据到全局
  → 不存在 → 创建新用户记录 → 加载空数据
  → 首页渲染
```

### 4.2 解锁流程

```
用户完成任务（通关/A评级/拍照/涂色）
  → 云函数检查解锁条件
  → 小狮未在 unlockedLions 中？
    → 是：追加到 unlockedLions
    → unlockedLions 达到 4 且无土土狮？→ 追加土土狮
    → 更新 title（≥3 只 → "舞狮小传人"）
    → 返回 { newUnlock: "huhuo"|"mumu"|"jinjin"|"shuishui"|"tutu"|"" }
  → 前端收到 newUnlock → 触发全屏解锁动画
  → 动画结束 → 刷新首页/个人中心小狮展示
```

### 4.3 作品保存流程

```
用户点击保存
  → Canvas.toTempFilePath() 导出图片
  → wx.cloud.uploadFile({ cloudPath, filePath }) 上传云存储 → 获得 fileID
  → 云函数 saveWork({ fileID, recordType, metadata }) 写数据库
  → 云函数内部检查首次完成 → 解锁小狮
  → 返回保存成功 { newUnlock: "jinjin"|"shuishui"|"" }
  → 分享操作：wx.showShareImageMenu({ path: fileID }) 分享到微信
```

> 注意：文件上传在**前端**调用 `wx.cloud.uploadFile`，云函数只负责写数据库 + 解锁检查，不处理文件上传。云函数端无法访问本地临时文件。

## 5. 云函数详细设计

### 5.1 `getOpenId`

```
输入：wx.login() 返回的 code
逻辑：调用 cloud.openapi.wxacode 换取 openId
输出：{ openId }
```

### 5.2 `getCMSData`

```
输入：无（或指定 type: "songs"|"stickers"|"outlines"|"decorations"|"products"）
逻辑：读取对应 CMS 集合，按 order 排序
输出：{ data: [...] }
```

### 5.3 `saveScore`

```
输入：{ songId, mode, score, stats: { perfect, good, miss, maxCombo, cooperation } }
逻辑：
  1. 写入 drum_records 集合
  2. 计算评级（S/A/B/C）
  3. 查询 users.unlockedLions
  4. 通关且未解锁火火狮 → 追加
  5. S/A 评级且未解锁木木狮 → 追加
  6. unlockedLions 达到 4 只且无土土狮 → 自动追加土土狮
  7. 更新 users.drumStats + title
输出：{ rating, newUnlock: "huhuo"|"mumu"|"tutu"|"" }
```

### 5.4 `saveWork`

```
输入：{ fileID, recordType: "artwork"|"photo", metadata: { canvasId?, stickerId?, type? } }
逻辑：
  1. 根据 recordType 写入 artworks 或 photo_records 集合
  2. 查询 users.unlockedLions
  3. 检查首次完成条件：
     - 首次涂色且未解锁金金狮 → 追加
     - 首次 AR 拍照且未解锁水水狮 → 追加
  4. unlockedLions 达到 4 只且无土土狮 → 自动追加土土狮
  5. 更新 users.unlockedLions + title
输出：{ newUnlock: "jinjin"|"shuishui"|"tutu"|"" }
```

### 5.5 `getUserData`

```
输入：无（从 context 获取 openId）
逻辑：
  1. 查询 users 集合
  2. 查询最近 3 条 artworks（作品缩略）
  3. 查询最近 5 条 drum_records（最近成绩）
输出：{ user, recentArtworks, recentRecords, lionStatus }
```

### 5.6 `deleteRecord`

```
输入：{ recordId, type: "artwork"|"photo" }
逻辑：
  1. 删除 artworks/photo_records 集合记录
  2. cloud.deleteFile() 删除云存储文件
输出：{ success: true }
```

## 7. 关键技术实现方案

### 7.1 鼓点判定引擎

```
核心循环：
  setInterval(() => {
    const now = Date.now() - startTime
    const activeBeats = beats.filter(b => 
      Math.abs(b.time - now) <= 150  // 150ms 判定窗口
    )
    // 如果有未判定的鼓点进入窗口 → 等待用户敲击
    // 如果用户敲击 → 匹配最近鼓点 → perfect/good
    // 如果鼓点超出窗口 → miss
  }, 16)  // 60fps 精度
```

- 使用 `Date.now()` 计时，不依赖音频播放进度
- 防抖：同一鼓点位置 300ms 内忽略重复敲击

### 7.2 涂色区域填充

```
Canvas 2D 实现：
  1. 线稿图作为底层 layer
  2. regions 数据预定义封闭路径
  3. 用户点击 → 命中测试 (ctx.isPointInPath)
  4. 选色 → ctx.fill() 填充命中区域
  5. 分层渲染：线稿层在上，颜色层在下
```

### 7.3 AR 贴纸合成

```
流程：
  1. CameraContext.takePhoto() → 临时照片路径
  2. Canvas 绘制：照片作为底层 + 贴纸 PNG 作为上层
  3. 贴纸支持 touchmove 拖拽、pinch 缩放/旋转
  4. Canvas.toTempFilePath() 导出合成图
```

### 7.4 帧率检测

```js
let lastTime = Date.now()
let frames = 0
function checkFPS() {
  frames++
  const now = Date.now()
  if (now - lastTime >= 1000) {
    const fps = frames
    frames = 0
    lastTime = now
    if (fps < 30) this.disableParticles()
  }
  requestAnimationFrame(checkFPS)
}
```

### 7.5 手势冲突处理方案

交互文档定义了复杂手势优先级。实现策略：

| 手势 | 识别方式 | 优先级 |
|------|---------|--------|
| tap | touchstart → touchend 距离 < 12pt，时长 < 300ms | 最高 |
| long-press | touchstart 持续 ≥ 600ms 且位移 < 12pt | 最低 |
| drag | touchstart → touchmove 位移 ≥ 12pt（dead zone） | 中 |
| pinch | 双指 touchstart，计算双指距离变化 | 中 |
| swipe | touchstart → touchend 水平位移 > 50pt，时长 < 300ms | 中 |

```js
// 手势判断核心逻辑
let startX, startY, startTime, isDragging = false
const DEAD_ZONE = 12  // pt

onTouchStart(e) {
  ;({ x: startX, y: startY } = e.touches[0])
  startTime = Date.now()
  isDragging = false
  if (e.touches.length === 2) this.isPinching = true
}

onTouchMove(e) {
  const dx = e.touches[0].x - startX
  const dy = e.touches[0].y - startY
  if (Math.abs(dx) > DEAD_ZONE || Math.abs(dy) > DEAD_ZONE) {
    isDragging = true  // 突破 dead zone → drag 模式
  }
  if (isDragging) this.handleDrag(e)
  if (this.isPinching) this.handlePinch(e)
}

onTouchEnd(e) {
  if (!isDragging && !this.isPinching) {
    const elapsed = Date.now() - startTime
    if (elapsed >= 600) this.handleLongPress()
    else this.handleTap()
  }
  this.isPinching = false
}
```

- **旋转吸附**：贴纸编辑中，旋转角度自动吸附到 `0° / 15° / 30° / ... / 345°`（步进 15°）
- **装饰物吸附**：拖拽装饰物距目标吸附点 ≤ 40pt 时自动对齐
- **同元素冲突**：同一元素上 tap 优先于 drag，drag 优先于 long-press
